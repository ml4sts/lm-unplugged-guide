# LLMs UnPlugged Facilitator Guide

This site is a guide for facilitators on how to run the `LLMs Unplugged` activity developed by the [URI ML4STS Lab](ml4sts.com) led by [Dr. Sarah Brown](https://sarahmbrown.org/). This guide is developed in collaboration with [Kenya Andrews](https://leadershipportfolio.wixsite.com/kenyaandrewscv). 





::::{attention}
This guide is intended for reference use after attending a training workshop. If you would like to attend a training workshop, [sign up](https://forms.gle/xYHnJXtqQFEz5XRm6). 
::::::::::
